# givebackmyOneplus 🍉

Верните мне OnePlus: кастомизация в стиле OxygenOS 16 и очистка от рекламы
для Xiaomi / Redmi / POCO на HyperOS. Без root.

## Возможности (v0.1)
- **Тема** — акцентный цвет, форма и стиль иконок, предпросмотр на ваших
  приложениях. Собирает тему HyperOS (`.mtz`) в `Загрузки/givebackmyOneplus`.
  ⚗ Экспериментально: применение сторонних тем на глобальной HyperOS без root ещё проверяется.
- **Очистка** (через [Shizuku](https://shizuku.rikka.app/)) — удаление рекламных и лишних
  приложений Xiaomi только для пользователя (можно вернуть), скорость анимаций.
- **О приложении** — и кое-что внизу 🍉

## Скачать
GitHub → **Actions** → последний **Build APK** → артефакт `givebackmyOneplus-apk`.

Неофициальный проект, не связан с OnePlus и Xiaomi. Вся графика нарисована с нуля.
