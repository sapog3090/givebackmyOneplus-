# givebackmyOneplus 🍉

Верните мне OnePlus: фишки OnePlus и очистка от рекламы для
Xiaomi / Redmi / POCO на HyperOS. Без root.

## Возможности

### Функции OnePlus
- **Alert Slider** — три режима (звук / вибро / тишина) + плитка в шторку.
- **Live Alerts** — «пилюля» у камеры: музыка, таймер, звонок, навигация, загрузки.
- **Horizon Light** — подсветка краёв экрана при уведомлении.
- **Анимация зарядки** — 3 стиля: кольцо, молния, волна.
- **Zen Mode** — режим фокуса на 20/30/60 минут.
- **Режим чтения** — чёрно-белый экран (через Shizuku) + плитка.
- **Игровой режим** — плитка «Не беспокоить» для игр.
- **Shelf (Полка)** — язычок у края: батарея, память, быстрые действия.
- **Виджет** — часы, дата и заряд в стиле OnePlus.

### Очистка
Через [Shizuku](https://shizuku.rikka.app/): удаление рекламных и лишних
приложений Xiaomi (с откатом), скорость анимаций.

### Тема
Акцентный цвет, форма и стиль иконок, предпросмотр на ваших приложениях.
Применение тем на родном рабочем столе — после разблокировки загрузчика (root).
